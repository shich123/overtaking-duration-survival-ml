# Overtaking-Duration Survival Modeling on Rural Two-Lane Highways

This repository contains the processed data and Python code used to reproduce the manuscript-level survival analysis of overtaking duration on rural mountainous two-lane highways.

The workflow fits a conventional log-logistic accelerated failure time (AFT) model, a Random Survival Forest (RSF) model, and SHAP-based interpretation outputs for the trained RSF model.

## Repository Structure

```text

```

## Data

The final modeling dataset is stored in `data/final_analysis_dataset.xlsx`, sheet `Rsf`. It contains 93 overtaking observations, including 73 completed overtaking maneuvers and 20 right-censored observations.

The file `data/traffic_flow_data.xlsx` contains traffic-flow records used to reproduce the descriptive speed-distribution and traffic-composition outputs.

The raw UAV videos are not included in this repository because they may contain sensitive traffic-scene information and road-user privacy-related information. Requests for access to raw video data should follow the process described in the manuscript Data Availability Statement.

Variable definitions and coding rules are provided in `data_dictionary.md`.

## Requirements

Python 3.10 or later is recommended. Install the required packages with:

```bash
pip install -r requirements.txt
```

Main dependencies include:

- `lifelines` for the log-logistic AFT model
- `scikit-survival` for Random Survival Forest
- `shap` for model interpretation
- `pandas`, `numpy`, `matplotlib`, and `scikit-learn` for data processing and supporting analyses

## Reproduce the Analysis

Run all scripts from the repository root:

```bash
python code/00_prepare_data.py
python code/01_log_logistic_aft.py
python code/02_random_survival_forest.py
python code/03_shap_and_pdp.py
python code/04_descriptive_plots.py
```

On Windows, the same workflow can be launched with:

```bat
run_all.bat
```

Generated outputs are written to:

- `outputs/tables/`
- `outputs/figures/`
- `outputs/models/`

Generated outputs are ignored by Git by default so that the repository remains lightweight and reproducible.

Because the RSF model is stochastic and the sample size is limited, exact numerical values may vary slightly across Python package versions and random splits. The scripts are intended to reproduce the analysis workflow, processed modeling dataset, and main model-interpretation outputs.

## Interpretation Note for SHAP

The SHAP values generated by `code/03_shap_and_pdp.py` explain the RSF risk score returned by `RandomSurvivalForest.predict`. Positive SHAP values indicate an increase in the predicted RSF risk score, corresponding to a greater predicted tendency for earlier completion of an overtaking maneuver. They should not be interpreted as direct increases in overtaking duration.

## Privacy and Data-Use Notes

This repository provides the processed modeling dataset for scientific reproducibility. Raw UAV videos, traffic-scene records, and other field records are not distributed publicly because of traffic-scene sensitivity and road-user privacy considerations.
