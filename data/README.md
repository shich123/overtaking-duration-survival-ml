# Data Files

This directory contains the processed data needed to reproduce the survival-analysis workflow reported in the manuscript.

## Included files

- `final_analysis_dataset.xlsx`: processed overtaking-maneuver dataset. The scripts read the `Rsf` sheet.
- `traffic_flow_data.xlsx`: traffic-flow records used to reproduce descriptive speed-distribution and traffic-composition outputs.

## Not included

Raw UAV video files, traffic-scene records, and other field records are not included because they may contain sensitive traffic-scene information and road-user privacy-related information. Requests for access to restricted data should be directed to the non-author institutional contact listed in the manuscript Data Availability Statement.

The dataset in this repository is intended for reproducing the manuscript-level analyses. It should not be used to identify individual road users, vehicles, or exact field-operation details.
